The workspace is split into two sibling modules: `backend/` (FastAPI + Uvicorn serving the analysis API) and `frontend/` (static HTML/CSS/JS SPA). The root `README.md` documents the unified quick-start flow — install Python dependencies from `backend/requirements.txt`, optionally set `DASHSCOPE_API_KEY` via `.env`, then launch the server with `uvicorn backend.app.main:app`; the frontend is served at `http://localhost:8000` and calls the backend's REST endpoints. `.gitignore` enforces that secrets (`*.env*`) and Python build artifacts stay out of version control, keeping the repo clean for both child modules.
