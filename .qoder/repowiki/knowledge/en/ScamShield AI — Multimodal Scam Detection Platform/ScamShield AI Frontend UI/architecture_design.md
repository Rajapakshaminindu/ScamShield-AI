Single-page application composed of three flat files: `index.html` defines the two-column layout (input hub on the left, results panel on the right) with four tabbed input modes; `style.css` provides all styling via CSS custom properties and responsive grid; `app.js` handles DOM interactions and communicates with a backend REST API. The JS layer exposes four async submission functions (`submitTextAnalysis`, `submitUrlAnalysis`, `submitScreenshotAnalysis`, `submitVoiceAnalysis`) that POST to `/api/analyze/{text,url,screenshot,voice}` respectively — JSON payloads for text/URL and `FormData` for file uploads. A shared `displayResults(data)` function renders the response into the results card, mapping fields like `risk_score`, `scam_type`, `summary`, `detected_indicators`, `explanation`, `recommended_dos`, and `recommended_donts`. Tab switching is driven by `data-tab` attributes and `.active` class toggling. There is no build step, framework, or bundler — the page is served as static assets under `/static/`.
